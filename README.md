# FoodieApp

FoodieApp is an iOS app that helps people find affordable food from local
restaurants, bakeries, and markets near them. Restaurants list "surprise bags"
of food that would otherwise go to waste, and users reserve them and pick them
up at a set time.

---

## What you need

- A Mac running macOS 14 or newer
- Xcode 15 or newer
- An Apple ID (a free one is fine for the simulator)
- Access to the project's Firebase config file (see "Setup" below)
